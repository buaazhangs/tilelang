# T.reinterpret

按目标类型解读原值的位模式；用于表达式级位重解释。

```python
T.reinterpret(value, dtype)
```

## 参数

| 参数 | 说明 |
|---|---|
| `value` | 源表达式 |
| `dtype` | 目标类型（示例的源、目标等位宽） |

## 数据类型支持

| 输入类型 | 实测结论 |
|---|---|
| uint8, int8, uint16, int16, uint32, int32, uint64, int64, float16, float32, bfloat16, float8_e4m3fn, bool | Y |
| float8_e5m2 | 编译错误 |

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "int32"
torch_dtype = getattr(torch, dtype)
bits = torch.empty((), dtype=torch_dtype).element_size() * 8
out_dtype = f"uint{bits}" if dtype.startswith("int") else f"int{bits}"
torch_out_dtype = getattr(torch, out_dtype)

@T.prim_func
def kernel(A: T.Tensor((64,), dtype), B: T.Tensor((64,), dtype), C: T.Tensor((64,), out_dtype)):
    with T.Kernel(1):
        for i in T.serial(64):
            C[i] = T.reinterpret(A[i], out_dtype)

compiled = tilelang.compile(kernel, target="ascend")
i = torch.arange(64)
a_values = i % 13 if dtype.startswith("uint") else i % 13 - 6
a = a_values.to(torch_dtype)
b = (i % 3 + 1).to(torch_dtype)
expected = a.view(torch_out_dtype)
inputs = [a.npu(), b.npu(), torch.full((64,), 77).to(torch_out_dtype).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
