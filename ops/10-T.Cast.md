# T.Cast

以 TIR Cast 节点表达数值转换，目标 dtype 位于第一个位置。

```python
T.Cast(dtype, value, annotations=None)
```

## 参数

| 参数 | 说明 |
|---|---|
| `dtype` | 目标类型 |
| `value` | 输入表达式 |
| `annotations` | 可选节点注解，例如T.Cast(dtype, value, annotations={"round": "rn"}) |
同样，`annotations`里填的注解，不会实际改变cast生成的ascendC代码

## 数据类型支持
① 硬件和 TileLang 均支持。② 硬件可实现，当前 TileLang 标量路径不支持。③ 硬件或 OP 语义不支持。

`e4`、`e5` 分别表示 float8_e4m3fn、float8_e5m2。

硬件均能支持，tilelang不支持部分存在编译错误和精度错误两种问题

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "int32"
out_dtype = "float32"
torch_dtype = getattr(torch, dtype)
torch_out_dtype = getattr(torch, out_dtype)
# FP8 用字节缓冲区读写，标量表达式仍使用指定的源类型和目标类型。
src_storage = "uint8" if dtype.startswith("float8_") else dtype
dst_storage = "uint8" if out_dtype.startswith("float8_") else out_dtype


@T.prim_func
def kernel(A: T.Tensor((64,), src_storage), C: T.Tensor((64,), dst_storage)):
    with T.Kernel(1):
        src = T.alloc_shared((64,), src_storage)
        dst = T.alloc_shared((64,), dst_storage)
        T.copy(A, src)
        for i in T.serial(64):
            x = T.reinterpret(src[i], dtype)
            y = T.Cast(out_dtype, x)
            dst[i] = T.reinterpret(y, dst_storage)
        T.copy(dst, C)


compiled = tilelang.compile(kernel, target="ascend")
i = torch.arange(64)
values = (i % 15).float()
if not (dtype.startswith("uint") or out_dtype.startswith("uint")):
    values -= 7
if torch_dtype.is_floating_point:
    values += (i % 4) * 0.25
a = (i % 3 == 0) if dtype == "bool" else values.to(torch_dtype)
expected = a.clone() if dtype == out_dtype else a.float().to(torch_out_dtype)

initial = ~expected if out_dtype == "bool" else (~expected.view(torch.uint8)).view(torch_out_dtype)
src_npu = a.view(getattr(torch, src_storage)).npu()
dst_npu = initial.view(getattr(torch, dst_storage)).npu()
compiled(src_npu, dst_npu)
torch.npu.synchronize()
actual = dst_npu.cpu().view(torch.uint8)
assert torch.equal(actual, expected.view(torch.uint8)), (dtype, out_dtype)
```

## attn使用明细

标量转换用到 `uint32 → int64`、`bool → uint32`、`bool → int32`、`int32 → uint32`。
