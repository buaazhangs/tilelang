# T.simd.vld

从 UB 地址读取数据，按 dist 指定的方式组织到向量寄存器中。

```python
T.simd.vld(addr, dist="NORM", *, post_inc=None)
```

## 参数

| 参数 | 说明 |
|---|---|
| `addr` | UB 元素地址或 access_ptr |
| `dist` | 加载分布，默认 NORM |

## 数据类型支持
| 输入类型 | 实测结论 |
|---|---|
| uint8, int8, uint16, int16, uint32, int32, uint64, int64, float16, float32, bfloat16, float8_e4m3fn, float8_e5m2, bool | Y |

上表为NORM模式的结果

| `dist` 可选值 | 从 UB 怎么读 | 结果 lane 怎么排列 |
|---|---|---|
| `NORM`（默认）、`NORM_B8`、`NORM_B16`、`NORM_B32` | 连续读取 256 B | 保持原顺序：`[a0, a1, a2, a3, …]` |
| `BRC_B8`、`BRC_B16`、`BRC_B32` | 按后缀位宽读取一个值 | 将该值广播到所有 lane：`[a0, a0, a0, a0, …]` |
| `US_B8`、`US_B16` | 连续读取 128 B，做 2 倍上采样 | 每个元素重复两次：`[a0, a0, a1, a1, a2, a2, …]` |
| `DS_B8`、`DS_B16` | 从连续 512 B 中取偶数下标的元素 | `[a0, a2, a4, a6, …]` |
| `UNPK_B8`、`UNPK_B16`、`UNPK_B32` | 连续读取 128 B | 按源元素位宽看，每个元素后补一个 0：`[a0, 0, a1, 0, a2, 0, …]` |
| `UNPK4_B8` | 连续读取 64 B | 每个字节后补三个 0：`[a0, 0, 0, 0, a1, 0, 0, 0, …]` |
| `BLK` | 读取一个 32 B 数据块 | 整块重复 8 次。例如 FP32 的 `[a0, …, a7]` 作为一组重复 8 次 |
| `E2B_B16`、`E2B_B32` | 连续读取 8 个元素 | 每个元素填满一个 32 B 块。`E2B_B16` 中每个值连续重复 16 次，`E2B_B32` 中连续重复 8 次 |

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "float32"
torch_dtype = getattr(torch, dtype)
elem_bits = torch.empty((), dtype=torch_dtype).element_size() * 8
lanes = 2048 // elem_bits
n = lanes
store_dtype = "uint32" if elem_bits == 64 else dtype
store_bits = 32 if elem_bits == 64 else elem_bits
store_lanes = 2048 // store_bits
store_dist = f"NORM_B{store_bits}"

@T.prim_func
def kernel(A: T.Tensor((n,), dtype), C: T.Tensor((store_lanes,), store_dtype)):
    with T.Kernel(1):
        src = T.alloc_shared((n,), dtype)
        dst = T.alloc_shared((store_lanes,), store_dtype)
        T.copy(A, src)
        with T.SimdVF():
            x = T.simd.vld(src[0])
            p = T.simd.pset(store_bits)
            if elem_bits == 64:
                T.simd.vsts(dst[0], T.reinterpret(x, "uint32x64"), p, dist=store_dist)
            else:
                T.simd.vsts(dst[0], x, p, dist=store_dist)
        T.copy(dst, C)

compiled = tilelang.compile(kernel, target="ascend")
values = torch.arange(n) % 2 if dtype == "bool" else torch.arange(n) % 13 + 1
a = values.to(torch_dtype)
expected = a.view(getattr(torch, store_dtype))
inputs = [a.npu(), torch.zeros_like(expected).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
