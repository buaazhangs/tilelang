# T.fill

把同一个标量写入目标 Buffer 或切片内的每个元素。

```python
T.fill(buffer, value, annotations=None)
```

## 参数

| 参数 | 说明 |
|---|---|
| `buffer` | 目标 Buffer |
| `value` | 写入的标量 |

## 数据类型支持

| 输入类型 | 实测结论 |
|---|---|
| uint8, int8, uint16, int16, uint32, int32, uint64, int64, float16, float32, bfloat16, bool | Y |
| float8_e4m3fn, float8_e5m2 | 编译报错 |

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "float32"
torch_dtype = getattr(torch, dtype)

@T.prim_func
def kernel(C: T.Tensor((128,), dtype)):
    with T.Kernel(1):
        buf = T.alloc_shared((128,), dtype)
        T.fill(buf, T.cast(3, dtype))
        T.copy(buf, C)

compiled = tilelang.compile(kernel, target="ascend")
expected = torch.full((128,), 3).to(torch_dtype)
inputs = [torch.zeros_like(expected).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
