# T.simd.pset

生成 SIMD 谓词寄存器，用于控制后续操作生效的 lane。

```python
T.simd.pset(elem_width, dist="PAT_ALL")
```

## 参数

| 参数 | 说明 |
|---|---|
| `elem_width` | 谓词元素粒度（位）|
| `dist` | 掩码模式，默认 PAT_ALL |

lane 从 0 开始编号。令 `L = 2048 // elem_width`，表示一个 SIMD 数据寄存器的 lane 总数。

| `dist` 可选值 | 选中的 lane |
|---|---|
| `PAT_ALL` | 全1 |
| `PAT_ALLF` | 全0 |
| `PAT_VL1` | 第 0 个 |
| `PAT_VL2` | 前 2 个，即 0～1 |
| `PAT_VL3` | 前 3 个，即 0～2 |
| `PAT_VL4` | 前 4 个，即 0～3 |
| `PAT_VL8` | 前 8 个，即 0～7 |
| `PAT_VL16` | 前 16 个，即 0～15 |
| `PAT_VL32` | 前 32 个，即 0～31 |
| `PAT_VL64` | 前 64 个，即 0～63 |
| `PAT_VL128` | 前 128 个，即 0～127（8 位或 16 位元素示例） |
| `PAT_M3` | 下标为 3 的倍数，即 0、3、6、9…… |
| `PAT_M4` | 下标为 4 的倍数，即 0、4、8、12…… |
| `PAT_H` | 下标最低的一半。例如 FP32 有 64 个 lane，选中 0～31 |
| `PAT_Q` | 下标最低的四分之一。例如 FP32 有 64 个 lane，选中 0～15 |

## 数据类型支持

本接口无数据 dtype 形参

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "float32"
torch_dtype = getattr(torch, dtype)
elem_bits = torch.empty((), dtype=torch_dtype).element_size() * 8
lanes = 2048 // elem_bits
n = lanes
store_dist = f"NORM_B{elem_bits}"

@T.prim_func
def kernel(A: T.Tensor((n,), dtype), C: T.Tensor((n,), dtype)):
    with T.Kernel(1):
        src = T.alloc_shared((n,), dtype)
        dst = T.alloc_shared((n,), dtype)
        T.copy(A, src)
        T.copy(C, dst)
        with T.SimdVF():
            x = T.simd.vld(src[0])
            p = T.simd.pset(elem_bits, "PAT_VL1")
            T.simd.vsts(dst[0], x, p, dist=store_dist)
        T.copy(dst, C)

compiled = tilelang.compile(kernel, target="ascend")
values = (torch.arange(n) + 1) % 2 if dtype == "bool" else torch.arange(n) % 13 + 1
a = values.to(torch_dtype)
expected = torch.zeros_like(a)
expected[:1] = a[:1]
inputs = [a.npu(), torch.zeros_like(a).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
