# T.simd.vdintlv

把两个向量按顺序拼接，再将其中偶数位和奇数位分别送入两个结果寄存器。

```python
even, odd = T.simd.vdintlv(src0, src1)
```
把src0和src1按顺序拼接成视为一个src，even接收的是src[0],src[2] …… ,odd接收的是src[1],src[3] ……

## 参数

| 参数 | 说明 |
|---|---|
| `src0` | 第一个向量寄存器 |
| `src1` | 第二个同型向量寄存器 |

## 数据类型支持

| 输入类型 | 实测结论 |
|---|---|
| uint8, int8, uint16, int16, uint32, int32, float16, float32, bfloat16, float8_e4m3fn, float8_e5m2 | Y |
| uint64, int64 | 编译错误 |
| bool | 精度错误 |


## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "float32"
torch_dtype = getattr(torch, dtype)
elem_bits = torch.empty((), dtype=torch_dtype).element_size() * 8
lanes = 2048 // elem_bits
n = 2 * lanes
store_dist = f"NORM_B{elem_bits}"

@T.prim_func
def kernel(A: T.Tensor((n,), dtype), C: T.Tensor((n,), dtype)):
    with T.Kernel(1):
        src = T.alloc_shared((n,), dtype)
        dst = T.alloc_shared((n,), dtype)
        T.copy(A, src)
        with T.SimdVF():
            x = T.simd.vld(src[0])
            y = T.simd.vld(src[lanes])
            even, odd = T.simd.vdintlv(x, y)
            p = T.simd.pset(elem_bits)
            T.simd.vsts(dst[0], even, p, dist=store_dist)
            T.simd.vsts(dst[lanes], odd, p, dist=store_dist)
        T.copy(dst, C)

compiled = tilelang.compile(kernel, target="ascend")
values = torch.arange(n) % 2 if dtype == "bool" else torch.arange(n) % 13 + 1
a = values.to(torch_dtype)
expected = torch.cat((values[::2], values[1::2])).to(torch_dtype)
inputs = [a.npu(), torch.zeros_like(a).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
