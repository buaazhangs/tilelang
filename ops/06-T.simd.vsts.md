# T.simd.vsts

按分布和掩码把寄存器数据写到 UB。

```python
T.simd.vsts(addr, src, mask=None, dist="NORM_B32", extent=None)
```

## 参数

| 参数 | 说明 |
|---|---|
| `addr` | UB 目的地址或 access_ptr |
| `src` | 源向量寄存器 |
| `mask` | 谓词，默认按源类型生成 |
| `dist` | 存储分布，默认 NORM_B32 |
| `extent` | 可选访问范围（元素数） |

## 数据类型支持

| 输入类型 | 实测结论 |
|---|---|
| uint8, int8, uint16, int16, uint32, int32, float16, float32, bfloat16, float8_e4m3fn, float8_e5m2, bool | Y |
| uint64, int64 | 编译报错 |

| `dist` 可选值 | 写入 UB 的方式 | 写入量 |
|---|---|---:|
| `NORM_B8` | 按顺序写 256 个 8 位元素。掩码启用的 lane 写到对应位置，关闭的位置保留原值。 | 256 B |
| `NORM_B16` | 按顺序写 128 个 16 位元素，掩码规则同上。 | 256 B |
| `NORM_B32`（默认） | 按顺序写 64 个 32 位元素，掩码规则同上。 | 256 B |
| `ONEPT_B8` | 只写第 0 个 8 位元素 `src[0]`。该模式忽略掩码。 | 1 B |
| `ONEPT_B16` | 只写第 0 个 16 位元素 `src[0]`，忽略掩码。 | 2 B |
| `ONEPT_B32` | 只写第 0 个 32 位元素 `src[0]`，忽略掩码。 | 4 B |
| `PK_B16` | 每个 16 位 lane 取低 8 位。lane `i` 启用时，写入从 `addr` 起的第 `i` 个字节。 | 128 B |
| `PK_B32` | 每个 32 位 lane 取低 16 位。lane `i` 启用时，写入从 `addr` 起的第 `i` 个 16 位元素。 | 128 B |
| `PK4_B32` | 每个 32 位 lane 取低 8 位。lane `i` 启用时，写入从 `addr` 起的第 `i` 个字节。 | 64 B |

例如，`PK_B16` 对前两个源元素 `[0x1234, 0xABCD]` 取低 8 位。当这两个 lane 均启用时，目的地址的前两个字节依次为 `0x34`、`0xCD`。
另外，虽然现在`dist` 可选值可以选：`INTLV_B8`、`INTLV_B16`、`INTLV_B32`（两个源寄存器，交织写），但这些选项至少需要两个寄存器，与接口参数矛盾

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "float32"
torch_dtype = getattr(torch, dtype)
elem_bits = torch.empty((), dtype=torch_dtype).element_size() * 8
lanes = 2048 // elem_bits
n = lanes
store_dist = f"NORM_B{elem_bits}"

@T.prim_func
def kernel(A: T.Tensor((n,), dtype), C: T.Tensor((n,), dtype)):
    with T.Kernel(1):
        src = T.alloc_shared((n,), dtype)
        dst = T.alloc_shared((n,), dtype)
        T.copy(A, src)
        with T.SimdVF():
            x = T.simd.vld(src[0])
            p = T.simd.pset(elem_bits)
            T.simd.vsts(dst[0], x, p, dist=store_dist)
        T.copy(dst, C)

compiled = tilelang.compile(kernel, target="ascend")
values = torch.arange(n) % 2 if dtype == "bool" else torch.arange(n) % 13 + 1
a = values.to(torch_dtype)
expected = a
inputs = [a.npu(), torch.zeros_like(a).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
