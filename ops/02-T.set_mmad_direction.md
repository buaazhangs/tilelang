# T.set_mmad_direction

设置 AIC 后续 MAD指令（底层矩阵乘加指令：asc_mmad） 在一个矩阵块内沿 M 或沿 N 优先生出结果。
先生成一行结果nz块，选 "n"；先生成一列结果块，选 "m"

```python
T.set_mmad_direction(direction)
```

## 参数

| 参数 | 说明 |
|---|---|
| `direction` | 字符串 "m" 或 "n"，其余报错 |

## 数据类型支持

本接口无数据 dtype 形参

## Kernel 示例

```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "float16"
torch_dtype = getattr(torch, dtype)
accum_dtype = "int32" if dtype in ("int8", "uint8") else "float32"
torch_accum_dtype = getattr(torch, accum_dtype)

@T.prim_func
def kernel(A: T.Tensor((32, 32), dtype), B: T.Tensor((32, 32), dtype), C: T.Tensor((32, 32), accum_dtype)):
    with T.Kernel(1):
        a = T.alloc_l1((32, 32), dtype)
        b = T.alloc_l1((32, 32), dtype)
        c = T.alloc_l0c((32, 32), accum_dtype)
        T.set_mmad_direction("m")
        T.copy(A, a)
        T.copy(B, b)
        T.gemm(a, b, c, transpose_B=True, clear_accum=True)
        T.copy(c, C)

compiled = tilelang.compile(kernel, target="ascend")
source = compiled.get_kernel_source()
print(source) # 输出ascendC代码
assert "asc_set_mmad_direction_m();" in source, "Expected M-direction configuration in generated source"
a = (torch.arange(1024).reshape(32, 32) % 9 - 4).to(torch_dtype)
b = (torch.arange(1024).reshape(32, 32) % 5 - 2).to(torch_dtype)
expected = a.to(torch_accum_dtype) @ b.to(torch_accum_dtype).T
inputs = [a.npu(), b.npu(), torch.full_like(expected, -99).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
