# T.set_atomic

设置原子的多核数据写回GM

```python
T.set_atomic(op="add", dtype="float32")
```
写回完成后用 T.set_atomic_none() 恢复普通写。

## 参数

| 参数 | 说明 |
|---|---|
| `op` | add、max 或 min |
| `dtype` | GM 目的元素类型，默认 float32 |

## 数据类型支持

| 输入类型 | 实测结论 |
|---|---|
| uint8, uint16, uint32, uint64, int64, float8_e4m3fn, float8_e5m2, bool | 接口不接收 |
| int8, int16, int32, float16, float32, bfloat16 | Y |

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "float32"
torch_dtype = getattr(torch, dtype)
num_blocks = 4
width = 128

@T.prim_func
def kernel(A: T.Tensor((num_blocks, width), dtype), C: T.Tensor((width,), dtype)):
    with T.Kernel(num_blocks) as bx:
        a = T.alloc_shared((width,), dtype)
        T.copy(A[bx, 0:width], a)
        T.set_atomic("add", dtype)
        T.copy(a, C)
        T.set_atomic_none()

compiled = tilelang.compile(kernel, target="ascend")
weights = (2 ** torch.arange(num_blocks)).reshape(num_blocks, 1)
a = (weights * (torch.arange(width) % 4 + 1)).to(torch_dtype)
c_initial = torch.full((width,), 3, dtype=torch_dtype)
expected = c_initial + a.sum(dim=0, dtype=torch_dtype)
c = c_initial.npu()
compiled(a.npu(), c)
torch.npu.synchronize()
torch.testing.assert_close(c.cpu(), expected, rtol=0, atol=0)
```
