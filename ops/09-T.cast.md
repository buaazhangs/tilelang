# T.cast

将标量的数值转换为目标类型。

```python
T.cast(value, dtype, round="", sat=True, rbits=None)
```

## 参数

| 参数 | 说明 |
|---|---|
| `value` | 输入表达式 |
| `dtype` | 目标类型 |
| `round` | 舍入模式，默认空字符串 |
| `sat` | 饱和注解标志，默认 True |
| `rbits` | 随机舍入位，默认 None |
注：当前T.cast的lowering路径中，这三个参数：`round`,`sat`，`rbits`没有被实际处理

## 数据类型支持
| 输入类型 | 实测结论 |
|---|---|
| uint8, int8, uint16, int16, uint32, int32, uint64, int64, float16, float32, bfloat16, bool | Y |
| float8_e4m3fn | 精度错误 |
| float8_e5m2 | 编译错误 |

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "int32"
torch_dtype = getattr(torch, dtype)
out_dtype = "int32" if dtype == "float32" else "float32"
torch_out_dtype = getattr(torch, out_dtype)

@T.prim_func
def kernel(A: T.Tensor((64,), dtype), B: T.Tensor((64,), dtype), C: T.Tensor((64,), out_dtype)):
    with T.Kernel(1):
        with T.SimtVF(threads=64):
            for i in T.Parallel(64):
                C[i] = T.cast(A[i], out_dtype)

compiled = tilelang.compile(kernel, target="ascend")
i = torch.arange(64)
a_values = i % 13 if dtype.startswith("uint") else i % 13 - 6
a = a_values.to(torch_dtype)
b = (i % 3 + 1).to(torch_dtype)
expected = a.to(torch_out_dtype)
inputs = [a.npu(), b.npu(), torch.full((64,), 77).to(torch_out_dtype).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
