# T.if_then_else

按布尔条件选择两个表达式之一。

```python
T.if_then_else(cond, t, f)
```

## 参数

| 参数 | 说明 |
|---|---|
| `cond` | 标量布尔条件 |
| `t` | 真分支值 |
| `f` | 假分支值 |

## 数据类型支持

| 输入类型 | 实测结论 |
|---|---|
| uint8, int8, uint16, int16, uint32, int32, uint64, int64, float16, float32, bfloat16, bool | Y |
| float8_e4m3fn | 精度错误 |
| float8_e5m2 | 编译错误 |

## Kernel 示例
```python
import torch
import torch_npu
import tilelang
import tilelang.ascend.language as T

dtype = "int32"
torch_dtype = getattr(torch, dtype)

@T.prim_func
def kernel(A: T.Tensor((64,), dtype), B: T.Tensor((64,), dtype), C: T.Tensor((64,), dtype)):
    with T.Kernel(1):
        with T.SimtVF(threads=64):
            for i in T.Parallel(64):
                C[i] = T.if_then_else(i % 2 == 0, A[i], B[i])

compiled = tilelang.compile(kernel, target="ascend")
i = torch.arange(64)
a_values = i % 13 if dtype.startswith("uint") else i % 13 - 6
b_values = i % 3 + 1
if dtype == "bool":
    a_values, b_values = i % 3 == 0, i % 5 == 0
a = a_values.to(torch_dtype)
b = b_values.to(torch_dtype)
expected = torch.where(i % 2 == 0, a_values, b_values).to(torch_dtype)
inputs = [a.npu(), b.npu(), torch.full((64,), 77).to(torch_dtype).npu()]
compiled(*inputs)
torch.npu.synchronize()
actual = inputs[-1].cpu().contiguous()
assert torch.equal(actual.view(torch.uint8), expected.contiguous().view(torch.uint8)), (actual.flatten()[:8], expected.flatten()[:8])
```
